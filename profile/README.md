# AI Visibility Journal

AI Visibility Journal (AVJ) is an independent, English-language publication that researches how AI systems find, describe, cite and recommend brands.

We publish original studies with documented methods and, wherever licensing allows, open data; the AVJ Citation Index, a recurring measurement of how AI answer engines cite sources; evidence-led guides; and The Visibility Brief, a free weekly newsletter.

AVJ accepts no payment for rankings or coverage and is not affiliated with any AI visibility vendor. It is funded by its founder.

**Website:** [aivisibilityjournal.com](https://aivisibilityjournal.com)

## Repositories

- [`citation-index`](https://github.com/AI-Visibility-Journal/citation-index) — Analysis code for the AVJ Citation Index. Currently private. A public release is planned with the preregistration lock on 17 November 2026.
- A companion data repository for edition datasets (planned licence: CC BY 4.0, with a DOI at each release) has not yet been created.

The first Index edition is scheduled for December 2026.

## Licence and citation

Code in this organisation is released under the MIT Licence unless a repository says otherwise. Datasets will carry their own licence and DOI, stated on each edition page. Please cite the specific repository, edition or paper, and use the `CITATION.cff` file where one is provided.
